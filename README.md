# nerbe — заказ по QR

Гость сканирует QR-код на столе → открывается меню (с фото) → делает заказ →
заказ мгновенно появляется на мониторе у бариста/официанта с номером стола.
Есть отдельный QR для заказов «с собой».

Стек: **Next.js** (деплой на Vercel) + **Supabase** (база данных, realtime
и хранилище фото — бесплатного тарифа достаточно для одного кафе).

---

## ⚠️ Если после «Оформить заказ» ничего не происходит

Почти всегда причина в одном из трёх мест. Проверьте по порядку:

1. **Схема базы не применилась полностью.** В Supabase SQL Editor любая
   ошибка откатывает выполнение остальных команд в скрипте. Возьмите
   актуальный `supabase/schema.sql` из этой версии (он написан так, чтобы
   его можно было безопасно запускать повторно) и выполните его ещё раз
   целиком — Run.
2. **Переменные окружения не заданы в Vercel или заданы, но проект не
   передеплоен после этого.** Project → Settings → Environment Variables:
   должны быть `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
   После добавления/изменения переменных нужно сделать **Redeploy**
   (просто сохранить переменную недостаточно — старая сборка её не подхватит).
3. **Посмотрите в консоль браузера.** Откройте страницу стола на телефоне
   или в браузере → F12 → вкладка Console/Network при нажатии «Подтвердить
   заказ». Теперь при ошибке форма показывает текст прямо на экране
   (например «permission denied», «relation does not exist» и т.п.) —
   это подскажет точную причину.

Если всё это сделано, а заказ создаётся, но не появляется на `/kitchen` —
проверьте в Supabase: Database → Replication, что таблицы `orders` и
`order_items` включены в репликацию (это же делает и SQL-скрипт).

## 1. Создайте проект в Supabase

1. https://supabase.com → New project (бесплатный тариф).
2. **SQL Editor → New query**, вставьте содержимое `supabase/schema.sql`
   целиком и нажмите **Run**. Это создаст таблицы `orders`, `order_items`,
   `menu_items`, наполнит меню стартовыми позициями, включит realtime и
   создаст хранилище `menu-images` для фотографий блюд.
3. **Project Settings → API** → скопируйте `Project URL` и `anon public` key.

## 2. Задеплойте на Vercel

1. Загрузите код в репозиторий на GitHub.
2. На https://vercel.com → **Add New → Project** → выберите репозиторий.
3. В **Environment Variables** добавьте:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - (рекомендуется) `NEXT_PUBLIC_STAFF_PASSCODE` — код доступа к монитору
     кухни и редактированию меню, например `4517`
4. **Deploy**. Получите ссылку вида `https://ваш-проект.vercel.app`.

Через терминал — то же самое:

```bash
npm i -g vercel
vercel login
vercel
vercel env add NEXT_PUBLIC_SUPABASE_URL
vercel env add NEXT_PUBLIC_SUPABASE_ANON_KEY
vercel env add NEXT_PUBLIC_STAFF_PASSCODE
vercel --prod
```

## 3. Настройте меню и фото

Откройте `https://ваш-проект.vercel.app/admin/menu` (спросит код персонала,
если вы его задали). Там можно:

- добавлять позиции: категория, название, цена, фото;
- добавить фото к уже существующей позиции кнопкой «Фото»;
- скрыть позицию из меню без удаления («Скрыть» / «Показать») — например,
  если блюдо временно закончилось;
- удалить позицию.

Изменения применяются сразу — обновлять деплой не нужно.

## 4. Сгенерируйте и распечатайте QR-коды

`https://ваш-проект.vercel.app/admin/qr` → укажите число столов → **Печать**.
Каждая карточка ведёт на `/table/1`, `/table/2` и т.д., плюс одна общая
карточка «С собой». Приклейте их на столы/подставки.

## 5. Откройте монитор у продавца/бариста

```
https://ваш-проект.vercel.app/kitchen
```

Заказы появляются автоматически, без перезагрузки, сгруппированы по
статусу: **Новые → Готовятся → Готовы**. Кнопка на карточке переводит
заказ дальше. Держите вкладку открытой весь день — на планшете можно
добавить на домашний экран как отдельное «приложение».

---

## Как это устроено

- `/table/[номер]` и `/takeaway` — меню (загружается из Supabase, с фото)
  и оформление заказа.
- `/kitchen` — подписан на realtime-изменения в Supabase, обновляется без
  перезагрузки.
- `/admin/menu` — CRUD для позиций меню и загрузка фото в Supabase Storage
  (бакет `menu-images`, публичный на чтение).
- `/admin/qr` — генерирует QR-коды на лету по текущему домену.

## Что можно добавить позже

- Печать чека при новом заказе.
- Звуковое уведомление на мониторе при новом заказе.
- Онлайн-оплата — нужна отдельная интеграция с платёжным провайдером.
- Более строгая защита админки через Supabase Auth вместо общего кода.

## Локальная разработка

```bash
npm install
cp .env.example .env.local   # впишите свои supabase-ключи
npm run dev
```

Откройте `http://localhost:3000/table/1` и `http://localhost:3000/kitchen`
в двух вкладках, чтобы проверить, что заказ появляется мгновенно.
